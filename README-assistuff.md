# AssiStuff Framework

AssiStuff is an additive local-first framework that coexists with Noredur.
Noredur's name, references, and `src/noredur/` source tree are retained; the
AssiStuff package must not import from that tree. The historical `.nrdpkg`
package extension is retained as well.

For installation, CLI, GUI, model configuration, memory, skills, plugins,
voice status, and package workflows, see the full [README](./README.md).

Architecture decisions are recorded in [docs/adr/](./docs/adr/), including
ADR-0001 through ADR-0010 for the original migration and implementation plan.
